# police — модульное CLI-приложение на Dart

Консольное приложение для учёта сотрудников, лиц, происшествий и их участников с хранением данных в SQLite.

## Предметная область

Система автоматизации отделения полиции:

- сотрудники (`Employee`);
- лица (граждане, `Person`);
- происшествия (`Incident`) с привязкой к сотруднику;
- участники происшествий (`Involvement`) – связь между происшествием и лицом с указанием роли.

## Архитектура и структура папок

Проект разделен на модули по слоям:

```text
lib/
  police.dart              # публичный экспорт
  src/
    domain/                # сущности и валидаторы
      models/
        identity.dart
        employee.dart
        person.dart
        incident.dart
        involvement.dart
      validators/
        validators.dart
    data/                  # SQLite и SQL-логика
      police_database.dart
    cli/                   # меню и обработка ввода
      menu.dart
      input_helper.dart
bin/
  main.dart                # точка входа
test/
  domain_test.dart         # тесты toMap/fromMap
  data_test.dart           # тесты БД
  validation_test.dart     # тесты валидации
```
## Что вынесено в каждый слой и почему

- `domain`: описывает данные и преобразования (`toMap`/`fromMap`), а также чистые функции валидации. Слой не зависит от SQL и консоли.
- `data`: отвечает за хранение, создание таблиц и CRUD-запросы.
- `cli`: отвечает за взаимодействие с пользователем (`stdin`/`stdout`) и навигацию по меню.
- `bin`: только запуск приложения и закрытие ресурсов.

Такое разделение упрощает поддержку, тестирование и замену инфраструктуры (например, SQLite на другой способ хранения).

## Реализованная функциональность

- просмотр списка сотрудников, лиц, происшествий и участников;
- добавление и удаление сотрудников;
- добавление и удаление лиц;
- добавление и удаление происшествий;
- добавление и удаление участников (связей);
- вывод всех таблиц БД в консоль.

## Валидация

Реализованы проверки:

- обязательный текстовый ввод: значение не пустое после `trim()`;
- числовое поле для стажа сотрудника: должно быть целым числом больше 0;
- дата/время: поддерживается `DateTime.parse()` и формат вида `YYYY-MM-DD HH:MM[:SS]`.

## Тесты

В проекте есть 3 обязательных типа тестов:

1. `toMap/fromMap` для сущности `Employee`;
2. вставка и чтение сотрудника из временной SQLite;
3. валидный и невалидный парсинг даты/времени.
